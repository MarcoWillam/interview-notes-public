# 面谈 · 面试评估工作台

面向线下面试的 Chrome 网页应用。当前版本可导入 Word 简历、保存面试偏好模板、录音、暂停、回放、下载、校对对话、填写人工结论和导出 Markdown，并自动保存在本地浏览器。用户选择稍后配置服务，因此默认不启用自动转写和 AI 评估；没有模拟报告。

## 本地使用

需要 Node.js 22.13+（测试推荐 Node.js 24）。

```sh
npm ci
cp .env.example .env
npm run dev
```

Chrome 打开终端打印的 localhost 地址。正式环境必须使用 HTTPS。填写岗位和要求，确认已取得录音同意，再点击开始录音。

录音每秒分片写入 Chrome 的 IndexedDB；候选人资料、简历正文、对话、结论与偏好模板也自动保存。刷新后恢复最近记录，通过“本地面试记录”切换、下载或删除。数据属于当前设备、浏览器和网站地址，清除站点数据、无痕退出、换设备或换地址不能恢复；下载到文件夹的音频是独立备份。服务器不持久保存录音。多标签只允许一个工作台写入。

单场录音上限为 4 小时或约 256 MiB；单次自动转写仍限制 20 MiB，较大录音需下载后分段处理。崩溃、断电、系统休眠可能导致末尾片段丢失，恢复时标记不完整。空间不足会停止录音，保留失败片段在页面内存，提供下载和重试保存；读取失败也保留恢复入口。未备份录音会阻止普通切换并提示离开，但浏览器不保证所有关闭场景都触发提示。可在本地记录中删除旧面试释放空间和申请持久保存。

Word 简历支持 DOC（Word 97–2003）和 DOCX，最大 5 MiB、提取正文最多 30,000 字符。浏览器 Worker 本地解析纯文本，原文件不上传也不保存；加密、损坏、扫描图片或更早的 Word 格式需转换后导入。导入后需校对；简历作为待核实背景，AI 引用证据只能来自面试对话。在页头“全局设置”管理通用默认标准、岗位模板及新面试默认模板。支持评估维度、重点考察事项、补充评分标准和报告要求。新建面试复制已保存的默认标准；面试页可以选择模板或展开“查看 / 调整本场标准”。本场修改不反向同步，修改全局或模板不改动当前及历史面试。删除默认模板会回退通用标准。旧版本本地数据在升级时保留。

## 接入模型服务

本地通过 Cloudflare Vite/Wrangler 加载项目 `.env`。如使用 `.dev.vars`，它优先于 `.env`。部署后在 Sites 的服务端环境变量中填写同名配置，重新部署生效。

| 功能 | 地址                | 密钥               | 模型             |
| ---- | ------------------- | ------------------ | ---------------- |
| 转写 | `ASR_BASE_URL`      | `ASR_API_KEY`      | `ASR_MODEL`      |
| 分析 | `ANALYSIS_BASE_URL` | `ANALYSIS_API_KEY` | `ANALYSIS_MODEL` |

BASE_URL 必须是 HTTPS，并包含提供商要求的版本前缀；末尾不包含具体接口路径。例如 `https://your-provider.example/v1`。转写请求追加 `/audio/transcriptions`，使用 multipart `file/model/response_format=json`，期望返回 `{ "text": "..." }`。分析追加 `/chat/completions`，要求提供商支持 `response_format: {type: "json_object"}`，从 `choices[0].message.content` 读取 JSON。

两项服务可以来自不同提供商。兼容接口不代表所有模型均支持，需要选定服务后验证文件格式、请求时限、模型名称和结构化输出。只有用户点击转写或分析时才发送对应资料（分析包含简历正文及面试偏好），本站不持久保存音频或文本。密钥只留在服务端，不使用 NEXT_PUBLIC 前缀。配置检查仅检查字段是否齐全，不代表真实请求已经验证。

转写不会可靠识别真实身份；用户需校对说话人。AI 输出按原文验证引用；无证据不能评分；所有结果需人工确认。逐字匹配只能验证引用存在，不能证明模型对引用的解释正确。

## 验证

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

自动化覆盖 DOC/DOCX 解析、本地数据恢复和删除隔离、录音保存/读取失败后的恢复、输入限制、暂停计时、未配置服务、跨来源请求、请求大小、服务契约、上游错误隐藏、评分范围与引用原文真实性。服务测试使用确定性的 HTTP 替身，没有调用收费模型。

实际笔记本麦克风授权、设备中断、长时间录制和真实提供商尚需在 Chrome 做端到端验收。本轮未进行浏览器界面测试。可选 WebMCP `get_interview_assessment` 在支持环境中注册只读工具，当前无可用 WebMCP 验证上下文，不声称已联调通过。

设计范围见 `docs/spec.md` 和 `docs/enhancements.md`；实施记录见 `docs/superpowers/plans/2026-09-08-interview.md`。

Lint 覆盖自写应用、服务与测试；第三方 DOC 解析器保留上游风格及许可证，排除在自写代码检查之外；模板附带的未使用 Shadcn 组件保留原样，其已有 lint 报告不属于本次修改。
