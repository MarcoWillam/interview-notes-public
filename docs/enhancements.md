# 简历、面试偏好与本地保存

用户要求：导入 Word 简历；配置可复用的面试偏好；大录音保存在本地，减少服务器存储。

实现方向：DOC（Word 97–2003）和 DOCX 在浏览器专用 Worker 内提取纯文本，不上传、不渲染文档 HTML。导入后可校对简历；简历作为待核实背景进入分析，不替代面试原文证据。加密、损坏、过大或无正文文件明确失败。偏好模板保存岗位、岗位要求、评估维度、重点考察事项，应用时使旧评估失效，不带入候选人资料。

录音使用 IndexedDB 逐片写入当前设备，页面刷新可恢复已落盘片段；结束后可回放和下载。本地列表保存面试资料和录音，支持恢复与明确确认后的删除。多标签同时写入由浏览器锁避免冲突。浏览器持久化申请和容量估计可见；清除站点数据、无痕退出、换设备无法保留记录，下载文件仍是独立备份。自动转写仍需用户主动发送录音，服务器不持久存储。

本地录音最大 4 小时或 256 MiB，现有单次转写限制仍为 20 MiB，较大录音可下载后分段处理。录音保存失败立即停止并提供可恢复音频下载，不能虚报完整保存。

验证：真实格式 DOC/DOCX 固定测试夹具；损坏/加密/大小边界；IndexedDB 分片顺序、恢复、会话删除隔离、模板复用；简历/偏好传入分析和导出；运行原有测试、类型、lint、构建和生产 HTTP 检查。除非用户要求，不执行浏览器 UI 测试。
