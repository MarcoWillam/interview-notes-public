# 面谈：线下面试评估工作台

2026-09-08。用户已同意开始第一版，并明确先完成网页、稍后配置服务。

## 范围

Chrome 网页工作台；岗位、岗位要求、候选人和评估维度可编辑。知情确认后申请麦克风，支持录音、暂停、继续、结束、回听和下载。结束后调用可配置语音服务转写；未配置时保留手动录入入口。对话可校对。评估依据岗位要求和用户配置维度；每个判断引用原文，找不到证据则不评分。人工填写最终意见并确认，支持 Markdown 导出。

第一版不做实时字幕、自动身份识别、候选人排名和自动录用决定。分析内容只来自对话和工作相关标准，不从声音推断人格、情绪或敏感属性。

## 交互与状态

一张面试工作台，三个页签：面试录音、对话记录、结论评估。右侧常驻岗位与标准。录音使用真实麦克风电平，不展示模拟转写或模拟分析。录音最大 60 分钟或 20 MiB，到达边界自动结束并保留音频。刷新或关闭前提示导出；本版数据仅存在当前页面内存，不上传到本站存储。用户主动转写时音频才发送给配置的服务，分析时才发送岗位与校对后的文本。

每次修改文本、岗位或维度，旧评估和人工确认作废。录音过程中不能更换面试。新增面试需要确认清除当前内容。麦克风拒绝、无设备、无安全上下文、设备中断、网络错误都显示可操作的错误信息。

## 服务边界

转写使用可配置的 multipart /audio/transcriptions 格式；分析使用 JSON /chat/completions 格式。两项分别配置服务端 API 地址、密钥与模型。密钥不进入浏览器。配置缺失返回 503 并显示未接入状态。外部适配器需实际提供商联调，当前不宣称已通过真实模型验证。

## 验收

验证请求校验、未配置状态、引用原文真实性、评分范围、录音状态转换、报告失效和导出。运行 TypeScript、测试、生产构建及 HTTP 冒烟。真实硬件麦克风与真实模型调用需用户配置后在 Chrome 验收。
