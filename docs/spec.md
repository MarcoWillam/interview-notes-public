# 面谈：面试材料评估工作台

2026-09-08。用户已确认新方案并要求实施：简历支持附件提取或粘贴文本，面试过程限定 `.md`，仅构建本地预览。

## 范围与流程

Chrome 工作台保留三个页签：候选人简历、面试记录、结论评估；右侧提供候选人、岗位模板与本场标准。简历直接粘贴，最大 30,000 字符。录音和转写由用户在豆包完成，工作台仅导入 UTF-8 `.md`（大小写扩展名均支持），最大 1 MiB / 80,000 字符。无 OCR、现场录音或语音配置入口；Word/PDF 仅用于简历导入。

上传后按纯文本预览编辑，保留发言标签、时间戳和 Markdown 内容，不执行其中 HTML。文件空白、编码错误、二进制、超限或读取失败时保留原数据。重新上传已有正文需确认替换；成功导入才清除旧评估、人工确认及校对确认。人工意见保留供核对。编辑内容后需重新确认。

选择岗位模板，校对说话人和文本后，按岗位要求、维度、简历背景与面试对话生成评估。输出维度说明、原文证据、无证据标记和待核实问题。最终意见由面试官填写确认，支持导出 Markdown。本地 Codex 未登录时显示真实状态，不模拟报告。

## 数据与服务

自动保存当前浏览器 IndexedDB，文件正文与来源名保存，原上传文件不额外保存。刷新恢复最近面试，支持历史切换与删除。全球默认标准与本场快照规则沿用现有实现；不改动历史面试。旧录音保留历史下载入口，主页不加载录音模块。

本地分析通过 Node 网关调用 Codex CLI，沿用本机 ChatGPT 登录，无需 API 密钥。只在用户主动生成时发送材料给 OpenAI，限定只读沙箱和无外部工具的临时运行，忽略用户配置，结构化输出。旧 `/chat/completions` 适配器另行保留，非本地默认路径。引用须匹配面试正文，证据不足不可评分，简历不得当成已验证面试证据；不自动决定录用。

## 验收

测试文件类型、大小、UTF-8、BOM/换行、二进制、80,000 字符边界、读取错误、材料本地保存与恢复、旧数据兼容及服务验证。类型、lint、构建通过，localhost:8787 返回正常页面。仅本地交付，不发布；真实 Codex 分析以虚构样例验证，不自动读取历史面试。

## 服务器网页与本地电脑（当前默认模式）

用户已批准改造为远程网页 + 本地 Codex 连接器；本轮仍仅本地预览，不部署。新增独立静态入口与 Node 24/SQLite 服务。生产模式使用账号会话；本机预览免登录并自动启动一个独立连接器，预览数据库与正式数据库分开。

浏览器提交材料生成持久任务，电脑持可撤销令牌主动领取自己账号的任务，沿用本机 Codex ChatGPT 登录，回传结果。一次性配对码 10 分钟有效，设备令牌只用于工作接口。浏览器不接触 Codex 凭据，服务器也不保存此凭据。

任务状态：queued → running → completed / failed / cancelled。每台电脑单次领取，60 秒租约，10 秒心跳；中断不自动重复消耗额度。关闭网页只停止观察，明确取消才取消任务。顶部任务列表可在重新打开后查进度、查看和下载报告，不覆盖其他本地面试。队列等待最多 24 小时，终态清除输入，报告与任务保留 7 天。

完整面试草稿、人工意见与全局模板仍保存在浏览器，生产账号之间使用不同 IndexedDB；本机预览保留旧数据。提交任务所需输入和结果另存服务器。结果仍按原文与维度校验，最终意见由面试官确认。

远程模式支持离线排队，无在线电脑时不禁用生成按钮。状态仅反映设备心跳及 Codex 登录检查，运行时错误（网络、额度、结构）仍会终止任务并展示通用原因。部署要求与数据保留见 `docs/deployment.md`。旧的直接 Node 网关通过 `start:local` 保留，非当前默认。

## 简历附件与阅读

支持 DOC/DOCX 和文字版 PDF（5 MB，PDF 30 页，提取后 30,000 字），在浏览器后台提取，原附件不上传。错误保留旧正文，替换需确认。用户核对正文后可单独提交 kind=resume 的 Codex 阅读任务，不需面试对话。结果按教育背景、工作经历、项目经验和技能分组，每条有逐字简历引用，缺失不编造、无评分，并给出岗位相关追问。正文和岗位标准修改会清除旧阅读，人工意见保留。来源文件名、正文、校对状态和阅读结果保存在本地历史；任务列表可找回和下载。旧队列行默认为 interview，旧连接器只领取 interview，避免把简历误当面试评估。两类任务沿用同样的隔离、租约、取消、重试及保留规则。
